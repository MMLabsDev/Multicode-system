
# MultiCode

**MultiCode** es una herramienta de línea de comandos en Python para codificar y decodificar texto en distintos formatos: **ASCII, binario, hexadecimal, Unicode y Base64**.

Empezó como un experimento para entender cómo funciona la codificación y terminó creciendo hasta convertirse en un proyecto modular y fácil de ampliar.

> 🚧 **Estado:** en desarrollo activo

---

## ⚡ Características

- 🔤 **ASCII**: codifica y decodifica texto
- 🔢 **Binario**: convierte texto a binario y viceversa
- 🔷 **Hexadecimal**: codifica y decodifica
- 🌐 **Unicode**: trabaja con representaciones Unicode
- 🔐 **Base64**: codifica y decodifica
- 📋 **Portapapeles**: copia los resultados directamente
- 🧩 **Arquitectura modular**: cada componente tiene una única responsabilidad

**En desarrollo:** detector de lenguaje y chatbot.

## 🚀 Arrancando:

### 1. Clone the repository

```bash
git clone https://github.com/MMLabsDev/Multicode-system
```

### 2. Enter the project

```bash
cd Multicode-system
```

### 3. Enter the main file
```bash
cd multicode
```

### 4. Install it in editable mode

```bash
pip install -e .
```

### 5. Run MultiCode

```bash
python main.py
```

Y eso es todo

Bienvenido a Multicode
